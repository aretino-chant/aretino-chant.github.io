# Cheatsheet

| Clefs ||
|---|---|
| `(g2)` `(f4)` `(c3)` | G, F, C clef |

| Pitch ||
|---|---|
| `a b c d e f g h i j k l m` | 13 positions, low to high |
| `a' b' … h'` | raised octave (with apostrophe) |

| Notehead ||
|---|---|
| `d`, `D`, `dt` | punctum, virga, tenor |
| `dw`, `dt`, `ds` | quilisma, small note |

| Suffix ||
|---|---|
| `d.`, `d_`, `d-`, `d~` | mora, episema, ictus, liquescent |
| `df/gh` | `/` = neume separator |

| Dividers / bars | |
|---|---|
| `'` | tiny breath mark |
| `,` | quarter bar (small caesura) |
| `;` | half bar |
| `\|` | full bar |
| `\|\|` | double bar (end of section) |
| `:\| \|: :\|:` | repeat sign |
| `\|\|\|` | final bar |

| Spacing / line break | |
|---|---|
| `(z)` `(Z)` | line break, justified / left-aligned |
| `= (sp) (sp2)` | fixed gap (scalable with a multiplier) |
| `*` | flexible gap (for justification) |

| Accidentals & key signature | |
|---|---|
| `(ibx)` | flat (the letter = pitch, e.g. `ebx`, `fbx`) |
| `(iby)` | natural |
| `(ib#)` | sharp |
| `(K:ibx jb#)` | key signature (repeats at the start of every line) |

| Text | |
|---|---|
| `w: Ky-ri-e` | text line (hyphen = syllable boundary) |
| multiple `w:` lines | multiple stanzas |
| `~` | tie several words to one note |
| `~~` | bind a stanza number (e.g. `1.~~Ky-ri-e`) |

| Header | Meaning |
|---|---|
| `;title: Title` | title (centered, bold) |
| `%%` | end of header |
